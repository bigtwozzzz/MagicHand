# HaGRID 手势识别项目使用说明

本文档提供了完整的项目使用指南，包括环境激活、模型训练和测试等操作步骤。

## 1. 激活虚拟环境

### Windows 系统

在项目根目录下，打开命令提示符或PowerShell，执行以下命令：

```bash
# 激活虚拟环境
gestures\Scripts\activate

# 验证环境激活成功（命令行前应显示 (gestures)）
python --version
```

### 验证环境配置

激活虚拟环境后，可以运行以下命令验证CUDA和TensorFlow配置：

```bash
# 检查CUDA可用性
python cudaTest.py
```

## 2. 开始训练模型

### 2.1 基本训练命令

使用ResNet18模型进行训练：

```bash
# 单GPU训练
python run.py --command train --path_to_config configs/ResNet18.yaml
python run.py --command train --path_to_config configs/SSDLiteMobileNetV3Large.yaml

# 多GPU训练（如果有多个GPU）
python run.py -p configs/ResNet18.yaml -c train --n_gpu 2
```

### 2.2 其他可用模型配置

项目提供了多种预配置的模型，可根据需要选择：

```bash
# MobileNetV3 Large（轻量级模型）
python run.py -p configs/MobileNetV3_large.yaml -c train

# MobileNetV3 Small（更轻量级）
python run.py -p configs/MobileNetV3_small.yaml -c train

# ResNet152（更深层网络）
python run.py -p configs/ResNet152.yaml -c train

# ConvNeXt Base（现代卷积网络）
python run.py -p configs/ConvNeXt_base.yaml -c train

# Vision Transformer B16
python run.py -p configs/VitB16.yaml -c train
```

### 2.3 训练参数说明

训练过程中的关键参数（在配置文件中设置）：
- `epochs`: 训练轮数
- `batch_size`: 批次大小（已优化为64以避免内存问题）
- `num_workers`: 数据加载进程数（已优化为4）
- `learning_rate`: 学习率
- `img_size`: 输入图像尺寸

### 2.4 训练输出

训练过程中会生成以下文件：
- 模型检查点：保存在 `work_dir/模型名称/` 目录下
- 训练日志：TensorBoard日志文件
- 最佳模型：根据F1分数自动保存最佳性能模型

## 3. 测试模型效果

### 3.1 使用训练好的模型进行测试

```bash
# 在测试集上评估模型
python run.py -p configs/ResNet18.yaml -c test
```

### 3.2 使用演示脚本

运行演示脚本进行摄像头实时手势识别：

```bash
# 基本演示（实时摄像头手势识别，显示手势类型和边界框）
python demo.py -p configs/ResNet18.yaml

# 带手部关键点识别的演示（显示手势类型、边界框和手部关键点）
python demo.py -p configs/ResNet18.yaml -lm

# 使用其他模型配置进行实时识别
python demo.py -p configs/MobileNetV3_large.yaml
python demo.py -p configs/ConvNeXt_base.yaml
```

**演示功能说明：**
- 自动打开摄像头进行实时手势识别
- 显示手势类型标签（支持34种手势类型）
- 绘制手势检测边界框
- 显示实时FPS和帧数
- 按 'q' 键退出演示
- 使用 `-lm` 参数可额外显示手部关键点

### 3.3 查看训练日志

使用TensorBoard查看训练过程：

```bash
# 启动TensorBoard
tensorboard --logdir work_dir/ResNet18/logs

# 在浏览器中打开 http://localhost:6006 查看训练曲线
```

## 5. 常见问题解决

### 5.1 内存不足错误

如果遇到 `MemoryError`，可以调整配置文件中的参数：
- 减少 `batch_size`（如从64改为32）
- 减少 `num_workers`（如从4改为2）
- 减少 `prefetch_factor`（如从2改为1）

### 5.2 CUDA相关问题

```bash
# 检查CUDA版本兼容性
nvcc --version
python -c "import torch; print(torch.cuda.is_available())"
```

### 5.3 文件路径问题

确保数据集路径在配置文件中正确设置：
- `dataset_train`: 训练数据集路径
- `dataset_val`: 验证数据集路径
- `dataset_test`: 测试数据集路径
- `annotations_train/val/test`: 对应的标注文件路径

## 6. 性能优化建议

### 6.1 硬件配置建议
- GPU内存：建议8GB以上
- 系统内存：建议16GB以上
- 存储：建议使用SSD以提高数据加载速度

### 6.2 训练优化
- 使用混合精度训练以节省显存
- 根据硬件配置调整批次大小
- 使用数据并行训练（多GPU）

## 7. 退出虚拟环境

训练或测试完成后，可以退出虚拟环境：

```bash
# 退出虚拟环境
deactivate
```
